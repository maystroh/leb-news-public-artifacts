# Daily Briefing Video Prototype

## Core structure

1. Hook
   Open with one sharp editorial question pulled from the briefing.
2. Situation frame
   Give the shared fact pattern all newspapers react to.
3. Newspaper blocks
   One block per outlet or cluster of outlets.
4. Synthesis
   Contrast the competing narratives.
5. Closing question
   End on the unresolved line from the briefing.

## Strong directions to test

### 1. Editorial bulletin
- Cream paper background, red and gold accents, newsroom feel.
- Best when the voiceover is dense and analytical.

### 2. War-room map
- Animated map traces, location labels, headline cards, ticker.
- Best when we want more geography and escalation cues.

### 3. Split narrative
- Left/right or top/bottom motion language for opposing editorial camps.
- Best when polarization is the main story.

## Recommended first production pipeline

1. Keep the full article-level narration as the audio master.
2. Generate a shorter visual script from the same source text.
3. Time scenes to the voiceover instead of showing every spoken word on screen.
4. Use on-screen text for:
   - outlet name
   - key framing phrase
   - 1 short pull quote
   - closing synthesis
5. Add Arabic subtitles as a separate layer after timing is locked.

## What the current prototype already does

- Reads the source briefing from the WSL path.
- Splits the text into timed scenes.
- Renders a vertical Arabic-first Remotion composition.
- Produces intro, scene cards, and outro question.

## Best next improvements

1. Replace auto-generated scene titles with true outlet names.
2. Shorten on-screen body text to selected quotes instead of full paragraphs.
3. Add voiceover audio and align scene durations to exact timestamps.
4. Introduce visual motifs per newspaper cluster.
5. Add a lower-third ticker for the recurring diplomatic thread.
